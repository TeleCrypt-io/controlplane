# Security policy

Do not disclose vulnerabilities in public issues, pull requests, or chat
channels. Send a concise report, reproduction steps, and affected revision to
the TeleCrypt.io maintainers through a private contact channel.

Do not include credentials, access tokens, private keys, personal data, or
production account data in a report. The maintainers will acknowledge receipt,
assess impact, and coordinate a fix and disclosure timeline.

The project does not operate a public bug bounty program.
